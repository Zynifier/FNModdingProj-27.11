## FNModdingProj-27.11
> Fortnite Modding UProject, Based on 27.11 UEFN.

### How to use

Any VS2022-26 Version can build this UProject, with these dependencies installed:

-   **C++ profiling tools**
-   **Windows 10 SDK** (Latest should work fine)
-   **Unreal Engine Installer**

Right Click the UProject, Click Switch Unreal Engine Version, Then Use the Engine [Here](https://github.com/Zynifier/UnrealEngine)

Right Click the UProject Again, Click Generate Visual Studio Project Files, Open The sln, Then build!

You can now launch the UProject!
